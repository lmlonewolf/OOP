# Задание 1. Учебное расписание

Лабораторная работа 1, вариант 1. Консольная программа хранит занятия и проверяет возможность их проведения. Если исходное время не подходит, подбирает ближайшее допустимое начало в ту же дату.

## Возможности

- Очные и дистанционные занятия через общий абстрактный тип.
- Хранение дисциплины, преподавателя, группы, даты, интервала и вида занятия.
- Хранение аудитории только у очных занятий.
- Проверка занятости преподавателя, группы и аудитории.
- Проверка окна между разными форматами у одной группы.
- Подбор ближайшего времени без изменения даты и длительности.
- Подключение новых ограничений через общий интерфейс.

## Правила текущей реализации

1. Начало занятия — с **08:00 до 22:00 включительно**. Окончание может быть позже 22:00, но должно оставаться в пределах суток.
2. Занятия одного преподавателя, одной группы или в одной очной аудитории не пересекаются в одну дату.
3. При смене очного и дистанционного форматов одной группе требуется окно **не менее 95 минут** в обоих направлениях. Для преподавателя отдельное окно не проверяется.
4. Касание границ интервалов разрешено: конец одного занятия может совпасть с началом другого.
5. Поиск идёт по минутам в обе стороны. При равном расстоянии сначала проверяется более позднее начало.
6. Если допустимого времени нет, новое занятие не сохраняется. На другую дату программа его не переносит.

## Основные классы

`Date`, `Time`, `Duration` и `TimeInterval` представляют значения. Их поля неизменяемы. Перегруженные операторы сравнивают значения, складывают длительности, проверяют пересечение интервалов и задают вывод в поток.

`BaseLesson` хранит общие поля занятия. `IRLesson` добавляет аудиторию, `OnlineLesson` представляет дистанционный формат. `isOnline` определяет формат через виртуальный вызов.

`Constraint::check` возвращает пустую строку при отсутствии нарушения или строку с причиной. Наследники проверяют преподавателя, группу, аудиторию, переход между форматами и время начала.

`Schedule::addLesson` вызывает все правила. Если нужны изменения, последовательно проверяет кандидатов времени и сохраняет первый допустимый. `AddResult` сообщает об успехе, переносе, исходном и итоговом времени и причинах конфликта.

## Тесты

Проверяются сравнение и создание типов значений, сложение длительностей, пересечение и касание интервалов, формат вывода, конфликты ресурсов, окно для группы, ближайший перенос, границы начала и отказ при отсутствии времени.

`require` выводит `[OK]` при успехе. При ошибке выбрасывает исключение с названием проверки. `runTests` запускает набор, `makeLesson` создаёт тестовые занятия. Тестовое дополнительное ограничение демонстрирует расширение правил.
