# Лабораторная работа 1. Вариант 1

**Тема:** инкапсуляция, наследование, полиморфизм, рекурсивные структуры и алгоритмы с применением ООП.

В работе две независимые консольные программы на C++:

| Задание | Папка | Назначение |
|---|---|---|
| 1 | `Lab1A` | Учебное расписание с проверкой конфликтов и подбором времени |
| 2 | `Lab1B` | Поиск по текстовым документам на собственном бинарном дереве |


## Режимы работы

В обеих программах главное меню:

- `1` — автоматические тесты;
- `2` — ручное использование;
- `3` — готовый пример;
- `0` — выход.

Аргумент `--test` запускает только тесты, `--demo` — только демонстрацию.

Первое задание позволяет вводить занятия вручную. Второе при обычном запуске автоматически загружает `.txt` из `documents`; ручного добавления документов нет.

## Что реализовано

В первом задании используются неизменяемые типы даты и времени, перегруженные операторы, иерархия занятий и полиморфные ограничения. Новое правило подключается без изменения алгоритма подбора времени.

Во втором задании используются собственное шаблонное дерево поиска и общий шаблонный алгоритм пересечения. Документы и правила индексирования отделены от дерева. Узлами дерева владеют `unique_ptr`.
