# Задание 2. Индекс текстовых документов

Лабораторная работа 1, вариант 1. Консольная программа читает текстовые файлы из папки `documents` и строит индекс на собственном шаблонном бинарном дереве поиска.

## Возможности

- Автоматическая загрузка всех `.txt` из папки `documents` при обычном запуске.
- Поиск документов по одному слову или по всем словам запроса.
- Приведение русских и латинских букв к нижнему регистру.
- Вывод документов с ID и индекса «слово — список ID».
- Удаление документа из индекса и повторное чтение папки.
- Отдельные режимы тестов, ручной работы и демонстрации.

Документы вручную не добавляются. Метод `addDocument` используется внутри модели при загрузке папки и в тестах.

| `Lab1B.slnx`, `Lab1B.vcxproj` | Решение и проект Visual Studio |

## Работа с документами

1. Положи текстовые файлы в `documents`. Содержимое сохраняй в UTF-8.
2. Запусти программу: файлы загрузятся автоматически, появится соответствие ID именам файлов.
3. Выбери ручное использование и нужную операцию поиска.
4. После изменения содержимого или состава файлов выбери перечитывание папки.

Текущая реализация выбирает обычные файлы с расширением `.txt` без учёта регистра расширения. Другие расширения и вложенные папки пропускаются. Корректность UTF-8 отдельно не проверяется.

ID выдаются от 1 после сортировки путей. При изменении набора файлов и перечитывании ID могут поменяться. Если перечитывание завершилось ошибкой, прежний индекс остаётся.

## Меню

Главное меню: `1` — тесты, `2` — ручное использование, `3` — готовый пример, `0` — выход.

В ручном режиме:

- `1` — поиск одного слова;
- `2` — поиск всех слов запроса;
- `3` — показать индекс;
- `4` — показать документы;
- `5` — удалить документ из индекса по ID;
- `6` — перечитать папку `documents`;
- `0` — вернуться в главное меню.

Удаление из индекса не удаляет файл с диска. Перечитывание папки снова загрузит этот документ.

## Устройство индекса

`Document` хранит ID, путь и полный текст. `TextIndex` хранит документы в векторе и использует дерево для пар «слово — вектор ID».

`splitWords` выделяет последовательности русских и латинских букв и цифр. Остальные символы разделяют слова. Буквы переводятся в нижний регистр, включая `Ё`; `е` и `ё` различаются. Повтор слова в документе не дублирует его ID.

`searchWord` возвращает ID для одного выделенного слова. `searchAll` последовательно пересекает результаты всех слов через `intersection`. Пустой запрос или неизвестное слово даёт пустой результат.

`removeDocument` удаляет ID из всех записей его слов. Если список ID опустел, слово удаляется из дерева. В текущей версии для этого повторно разбирается сохранённый текст документа.

## Дерево и пересечение

`BinaryTree<Key, Value, Compare>` не зависит от документов. Типы ключа и значения, а также правило сравнения задаются шаблоном. По умолчанию используется `std::less<Key>`.

Дерево поддерживает `insert`, две версии `find`, `contains`, `erase` и `inorder`. Внутренние `eraseNode` и `inorder` работают рекурсивно. Повтор ключа отклоняется, значение сохраняется. Симметричный обход возвращает пары в порядке `Compare`.

Узлами владеют `unique_ptr`. Указатели из `get` и `find` не передают владение. Дерево не балансируется: операции зависят от его высоты. Реализация адаптирована из работы по алгоритмам; вставка по уровням заменена на вставку по сравнению ключей.

`intersection<T, Equal>` возвращает общие элементы двух векторов без повторов. Тип элемента и правило равенства заменяемы. Шаблоны определены в заголовках, чтобы их код был виден при подстановке типов.

## Автотесты

Тесты проверяют основной функционал по ТЗ: операции и порядок дерева, разные типы и сравнение, уникальность ID и ключей, регистр, отсутствие дублей, однословный и многословный поиск, пересечения, удаление документа и последнего вхождения слова.

Из файловых случаев оставлены загрузка папки, повторное чтение без дублей, пустой файл, файл только с пробелами и файл с пробелами в имени. Отдельных проверок неверного UTF-8, расширений, вложенных папок, BOM и специальных имён нет.

Нужный набор данных:

```text
test_data/
├── first.txt
├── second.txt
├── third.txt
├── duplicate.txt
├── empty.txt
├── spaces.txt
├── with spaces.txt
└── directory/
    ├── alpha.txt
    └── beta.TXT
```

`empty.txt` пустой, `spaces.txt` содержит только пробельные символы. `alpha.txt` и `beta.TXT` нужны для проверки загрузки папки и поиска общего слова. Остальные файлы проверяют индексирование, запросы и повтор ID.
